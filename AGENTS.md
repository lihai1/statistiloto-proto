# proto (shared gRPC contract)

Single source of truth for the Java↔Go↔Python gRPC contract. This repo contains ONLY
the `.proto` definition and google API annotations — no generated code, no build system.

## Contents

- `lottery.proto` — the contract. Package `lottery.v1`.
  - Service `LotteryService`: `HealthCheck`, `GenerateForm`, `GetStatistics`, `Analyze`, `Simulate`.
  - Messages: `DateWindow`, `GenerateFormRequest/Response`, `GetStatisticsRequest/Response`,
    `AnalyzeRequest/Response`, `Pair`, `NumberSet`, `FrequencyGroup/Entry`, health types,
    `SimulateRequest/Response`, `SimulateTierHit`, `SimulateDrawResult`,
    `SimulateTierSummary`, `SimulateSummary`.
  - Enum `Strength` (WEAK/STRONG).
  - Go package: `github.com/lihai1/stat-tree-server/pkg/gen;lotteryv1`.
  - Java package: `com.statistiloto.lottery.v1`.
- `third_party/google/api/` — grpc-gateway annotations (`annotations.proto`, `http.proto`).
- `third_party/google/protobuf/` — standard protobuf deps.
- `docs/FLOWS.md`, `docs/REQUIREMENTS.md` — contract flows + requirements.

## Regenerating stubs

This repo has NO Makefile or buf config. Stubs are generated by each consumer:

| Consumer | Command | Output |
|----------|---------|--------|
| Go (`lottery-stats-server/`) | `make proto` (in that repo) | `pkg/gen/` |
| Java (`server/`) | `./gradlew generateProto` (in that repo) | `build/generated/` |
| Python (`agent/`) | `make proto` (in that repo) | `app/gen/` |

Or from the orchestrator root: `make proto` (regenerates Go + Java), `make proto-go`,
`make proto-java`.

## Changing the contract

1. Inspect all consumers: `lottery-stats-server/internal/services/`, `server/src/main/java/.../service/`,
   `agent/app/tools/` + `agent/app/gen/`.
2. Edit `lottery.proto` here.
3. Regenerate stubs in ALL three consumers (see table above).
4. Update all three implementations.
5. Test all three: `make test-go`, `make test-java`, `make test-agent` (from orchestrator).

Do NOT duplicate protobuf DTO definitions in any service. Do NOT hand-edit generated stubs.

## Gotchas

- `third_party/google/` must be present for `protoc` to resolve google.api annotations.
  The Go `make proto` uses `--proto_path="proto/third_party"`.
- Go and Java package options are set in the proto file — changing them breaks all consumers.
- The proto is copied into each consumer's build context (Go has a local `proto/` copy;
  Java reads from `../proto/`). Keep them in sync — the canonical source is THIS repo.
